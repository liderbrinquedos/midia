# Desenho da fase 1

Frontend estático no Plesk, API FastAPI no Render e índice JSON substituível por SQLite/PostgreSQL. Busca por metadados no índice, sem varredura do drive por solicitação. A futura sincronização Graph pertence ao backend. Nenhuma credencial no frontend.

Interface em roxo e amarelo, busca principal, categorias, novidades, mais acessados demonstrativos e modal para mídias. Layout adapta navegação lateral para barra superior em telas menores. Estados vazios e erros têm retorno explícito.

Revisão inicial no navegador local; publicação e integração Microsoft dependem dos acessos e configurações reais.
